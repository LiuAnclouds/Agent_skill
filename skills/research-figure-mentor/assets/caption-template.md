# Caption Template

Use this structure when the user asks for figure captions or when the final figure needs a paper-style caption.

## Caption Skeleton

**Figure X. [Short direct title].**  
[Sentence 1: what the figure shows.]  
[Sentence 2: what the key contrast, mechanism, or conclusion is.]  
[Sentence 3: optional note about color groups, phases, or branches if needed.]

## Examples

**Figure 3. Dynamic graph anomaly detection model overview.**  
The figure shows the full node-edge-subgraph fusion pipeline used in the model.  
Target-node encoding, edge-aware aggregation, and subgraph-level pooling are kept as separate branches before the final prediction head.
