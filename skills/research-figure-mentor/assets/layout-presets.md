# Layout Presets

## 1. System Overview

- left: external actors or inputs
- center: core services or orchestration
- right: storage, outputs, or downstream systems
- bottom: optional monitoring, logging, diagnostics

## 2. Data Figure Panel

- top-left: headline comparison
- top-right: ranking or grouped contrast
- bottom-left: distribution or drift
- bottom-right: annotation-heavy supporting panel

## 3. Neural Model Figure

- left: inputs and preprocessing
- center: repeated encoder or block stack
- right: pooling, fusion, and output heads
- bottom or side: equations, notes, or configuration callouts

## 4. Multi-Branch Model Figure

- group each branch in a clear lane
- place convergence at one visible fusion point
- align repeated branches vertically or horizontally
- avoid routing arrows diagonally through unrelated blocks
