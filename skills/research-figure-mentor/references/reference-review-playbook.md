# Reference Review Playbook

## When To Use

Use web reference review when:

- the task is a neural model figure
- the task is a paper/thesis/midterm system figure
- the user asks for top-tier, top-conference, top-journal, or paper-quality style

## What To Search For

Search for strong examples that match the figure family, not only the domain topic.

Search pattern examples:

- `"graph neural network architecture figure pdf"`
- `"system architecture diagram paper figure"`
- `"workflow diagram paper architecture"`
- `"ablation result figure paper"`
- `"top conference model diagram figure"`

## Preferred Sources

- top conference or journal papers
- official project papers or docs
- high-quality surveys or tutorials with strong figure design

Prefer primary sources over derivative blog reposts.

## What To Borrow

- information layering
- box grouping
- branch layout
- color restraint
- legend placement
- annotation style
- emphasis strategy

## What Not To Borrow

- exact content
- exact module wording if it does not fit the current task
- layout choices that distort the real structure
- ornamental elements with no semantic value

## Refinement Rule

After reviewing references:

1. write down the style traits worth adopting
2. apply only the traits that improve clarity
3. re-run validation
4. reject any refinement that makes the figure less faithful
