# 论文笔记风格画像

这个文件记录 `article-note-mentor` 当前应稳定遵循的风格。

## 总体气质

目标风格是：

- 中文
- 研究型笔记
- 客观、严谨
- 解释密度高
- 可读，但不轻浮
- 带有明确的科学追求和研究精神

理想中点是：

- **比综述口吻松一点**
- **比聊天口吻稳很多**

## 正文应该像什么

正文应该像：

- 一个认真读论文的学生或研究者在做高质量自用笔记
- 一边梳理论文，一边把其中的道理讲清楚
- 重逻辑、重结构、重证据

而不应该像：

- 会议新闻稿
- 个人情绪化随笔
- 只有复述没有解释的摘抄

## 标题风格

标题应满足：

- 凝练
- 技术化
- 中性
- 有科学感、深度感、逻辑感
- 不宜过长，也不宜空泛过短

默认偏好：

- 优先短标题
- 常见长度以 2-6 个汉字或一个短技术短语为宜
- 不把整段论证压进标题里

## 编号体系

统一使用：

- 顶层：`一、二、三、四、五`
- 次级：`1. / 2. / 3.`
- 再次级：`1.1 / 1.2 / 1.3`

## 结构偏好

强偏好如下：

- 少标题、厚主题块
- 不写“一个标题只带两三句”的碎片化结构
- `Work` 永远是全文主体
- 实验、附录、补证尽量吸收到 `Work`
- 格式评论阶段只显化已存在的重要信息，不制造新的样式噪音

## 解释风格

默认采用 **垂直客观阐释**，而不是过度教学化类比。

解释一个公式、模块或实验时，优先顺序为：

1. 它是什么
2. 相关符号或术语是什么意思
3. 它在做什么
4. 为什么这样设计
5. 它在全文里起什么作用
6. 后文哪些证据支撑了它

## 类比使用规则

- 默认少用
- 只有复杂公式或抽象概念确实难以直接说明时才使用
- 类比只能辅助理解，不能替代正式阐释

## 动态排版

飞书友好并不等于样式堆砌。排版应服务于逻辑辨识速度。

推荐：

- 用 `**加粗**` 标出真正的核心判断、对比点、结论点
- 用 `*斜体*` 处理英文术语、概念和轻量强调
- 用 `` `inline_code` `` 处理模型名、符号名、字段名和命令式标识
- 用扁平分点提升扫描效率
- 用克制颜色强调标签或收束句

不推荐：

- 每一句都加粗
- 为了“有活力”而做花哨排版
- 让样式密度盖过内容密度
- 把格式评论阶段做成机械涂色

## 解释纪律

全文要明确区分：

- 论文原文明确写了什么
- 这是基于原文的合理阐释
- 这部分仍未被论文证明

不能把三者混写。
